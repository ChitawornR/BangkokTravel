## 🎯 Project Overview

**Bangkok Travel** is an educational project designed to practice building mobile apps using **.NET MAUI (Multi-platform App UI)** with **C#** and the **MVU (Model-View-Update)** architecture.

The app showcases a curated list of Bangkok tourist attractions loaded from a local JSON file, allows users to like their favorite spots, and supports theme switching.

---

## ✨ Features

- 📄 **Local Data Loading**  
  Attractions and their rankings are loaded from a custom-built JSON file

- ❤️ **Like & Save Favorites**  
  Users can mark places they like and revisit them later

- 🌗 **Theme Switching**  
  Supports both **Light** and **Dark** themes for better UI experience

- 🧱 **Built with MVU Pattern**  
  Built using the Model-View-Update architecture for clean and maintainable code

---

## 🛠 Tech Stack

- 🖥️ **.NET MAUI** — Cross-platform framework for building native apps  
- ☕ **C#** — Primary programming language  
- 🧭 **MVU (Model-View-Update)** — Architecture used for UI logic  
- 📦 **Local JSON File** — Static dataset for tourist attractions
